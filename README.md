 Heart Disease Prediction System

 Overview

This project uses Machine Learning to predict whether a person has heart disease based on medical attributes.
It helps in early detection by analyzing patient data and providing a prediction.

---

 Dataset

The dataset used in this project contains several medical features such as:

- Age
- Sex
- Chest Pain Type
- Blood Pressure
- Cholesterol
- Maximum Heart Rate
- وغيرها من العوامل المهمة

The target variable:

- "0" → No Heart Disease
- "1" → Heart Disease

---

 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

 Machine Learning Models

The project applies Machine Learning algorithms such as:

- Logistic Regression
- (Optional) Random Forest

---

 Project Workflow

1. Load and explore the dataset
2. Clean and preprocess the data
3. Split data into training and testing sets
4. Apply feature scaling
5. Train the model
6. Evaluate model performance

---

Results

The model is trained to achieve good accuracy in predicting heart disease.
Evaluation is done using metrics like accuracy score.
